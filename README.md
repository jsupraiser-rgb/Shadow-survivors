# Shadow Survivors

A dark hybrid action game combining:

- **Swordigo** → 2D side-scrolling adventure feel
- **Zelda** → Exploration & progression
- **Vampire Survivors** → Enemy waves & survival
- **Dead Cells** → Fast combat & mobility

## Current Features (v0.1)

- Touch joystick + attack & dash buttons (mobile friendly)
- Keyboard support (WASD / Arrow keys)
- Auto-spawning enemy waves that get harder over time
- Sword attacks that damage enemies
- Dash with brief invulnerability
- Health, Kills, Souls, and Timer
- Particle effects on hit & death

## How to Play

1. Open `index.html` in any modern browser
2. Or host on **GitHub Pages** for easy mobile testing
3. Use the virtual joystick to move
4. Tap ⚔️ to attack
5. Tap 💨 to dash

3. Go to Settings → Pages → Deploy from main branch
4. Open the GitHub Pages link on your phone
